##  Sobre o projeto

**Avengers Fan Hub** é um site feito por fã, para fãs, sobre o universo cinematográfico da Marvel. Ele reúne em uma única página a origem dos Vingadores nos quadrinhos e nos cinemas, curiosidades, perfis de heróis e vilões, uma linha do tempo dos filmes e partes interativas, como quiz e chat.

O projeto foi desenvolvido em grupo na graduação em **Análise e Desenvolvimento de Sistemas (UNICID)** para praticar construção de páginas web, navegação entre seções e layout responsivo.

##  Objetivo

- Reunir informações sobre os Vingadores e o MCU de forma organizada e fácil de navegar.
- Praticar **HTML, CSS e JavaScript** em um projeto com várias seções e partes interativas.
- Criar um layout **responsivo**, com navbar e rodapé, que funcione em telas de tamanhos diferentes.

##  Seções do site

| Seção | O que você encontra |
|---|---|
| **Início** | Tela de abertura com a chamada "O multiverso é real" e botões para explorar o site |
| **História** | A origem dos Vingadores nos quadrinhos (1963, por Stan Lee e Jack Kirby), a Iniciativa Vingadores no cinema, marcos importantes e criadores |
| **Curiosidades** | Fatos do MCU, como as aparições de Stan Lee, a ordem de lançamento versus a ordem cronológica e o vibranium |
| **Heróis** | 13 perfis: Homem de Ferro, Capitão América, Thor, Homem-Aranha, Hulk, Viúva Negra, Pantera Negra, Visão, Feiticeira Escarlate, Gavião Arqueiro, Homem-Formiga, Capitã Marvel e Doutor Estranho |
| **Vilões** | 8 perfis: Thanos, Loki, Ultron, Caveira Vermelha, Killmonger, Duende Verde, Dormammu e Kang |
| **Filmes** | Linha do tempo com 14 filmes, cada um com ano e um resumo de uma linha |
| **Quiz** | Quiz do Multiverso para testar o que você sabe sobre o MCU |
| **Chat** | Chat do Multiverso, com escolha de personagem e campo para enviar mensagens |

##  Funcionalidades

- 🎬 **Tela de introdução** com botões "Entrar no Multiverso" e "Pular intro"
- 🧭 **Navbar** com acesso rápido a todas as seções (Início, História, Curiosidades, Heróis, Vilões, Filmes, Quiz e Chat)
- 🦸 **Cartões de heróis e vilões**, com nome, descrição e ícone de cada personagem
- 🎞️ **Linha do tempo dos filmes** do MCU
- ❓ **Quiz interativo** sobre o universo Marvel
- 💬 **Chat** com seleção de personagem
- 📱 **Layout responsivo**, que se adapta a diferentes telas
- 🦶 **Rodapé** com links rápidos

##  Tecnologias utilizadas

| Tecnologia | Uso no projeto |
|---|---|
| **HTML5** | Estrutura das seções e do conteúdo |
| **CSS3** | Estilo, navbar, rodapé e layout responsivo |
| **JavaScript** | Interações: tela de introdução, quiz e chat |
| **GitHub Pages** | Hospedagem para acessar o site online |

Não precisa de servidor nem de instalação.
